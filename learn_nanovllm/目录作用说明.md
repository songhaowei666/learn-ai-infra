# Nano-vLLM 目录作用说明

本文档说明 [nano-vllm](https://github.com/GeeeekExplorer/nano-vllm) 项目各目录与核心文件的职责，便于阅读源码与学习。

> 学习笔记目录：项目同级 `learn-ai-infra/learn_nanovllm/`，通过软链接挂到仓库内的 `nano-vllm/learn_nanovllm`。

---

## 项目概览

Nano-vLLM 是一个从零实现的轻量级 vLLM，代码约 1200 行，支持离线推理、Prefix Caching、张量并行、Torch Compile、CUDA Graph 等优化。

整体分层：

```
用户 API (llm.py / sampling_params.py)
    → engine/          调度、序列、KV Block、模型执行
        → models/      具体模型结构（如 Qwen3）
            → layers/  Attention、Linear、Norm 等算子
    → utils/           权重加载、推理上下文
```

---

| 路径 | 作用 |

| `learn_nanovllm/` | 本地学习目录软链接（指向同级 `learn-ai-infra/learn_nanovllm`，不参与上游仓库） |

## `nanovllm/` — 核心 Python 包

对外导出 `LLM` 与 `SamplingParams`，是整个推理库的入口包。

| 文件 | 作用 |
|------|------|
| `__init__.py` | 导出公共 API：`LLM`、`SamplingParams` |
| `llm.py` | 用户侧入口类；实际继承 `LLMEngine`，做薄封装 |
| `config.py` | 引擎与运行时配置（模型路径、并行度、max 长度等） |
| `sampling_params.py` | 采样参数：temperature、max_tokens 等 |

---

## `nanovllm/engine/` — 推理引擎

负责请求生命周期：接入、调度、KV Cache 管理、驱动模型前向。对应 vLLM 的 Engine 层。

| 文件 | 作用 |
|------|------|
| `llm_engine.py` | 引擎主入口：接收 prompt、驱动 Scheduler 与 ModelRunner、返回生成结果 |
| `scheduler.py` | 请求调度：决定哪些序列做 prefill / decode，如何组 batch |
| `sequence.py` | 单条生成序列及其状态（等待、运行、完成等） |
| `block_manager.py` | KV Cache 的 Block 分配与回收；支持 Prefix Caching |
| `model_runner.py` | 实际执行模型前向；处理张量并行、CUDA Graph、Torch Compile 等 |

---

## `nanovllm/layers/` — 底层算子 / 网络层

可复用的 Transformer 组件，被 `models/` 组装成完整模型；多数层考虑了张量并行。

| 文件 | 作用 |
|------|------|
| `attention.py` | Attention 计算，以及 KV Cache 的写入（含 Triton kernel） |
| `linear.py` | 线性层及并行变体：Column / Row / QKV / Merged 等 |
| `rotary_embedding.py` | RoPE（旋转位置编码） |
| `layernorm.py` | RMSNorm |
| `activation.py` | SiLU + Mul（用于 SwiGLU / 门控 MLP） |
| `embed_head.py` | 词嵌入与 LM Head（支持词表并行） |
| `sampler.py` | 从 logits 采样下一个 token |

---

## `nanovllm/models/` — 具体模型结构

按模型结构把 `layers/` 拼成完整 Causal LM。

| 文件 | 作用 |
|------|------|
| `qwen3.py` | Qwen3 实现：Attention、MLP、DecoderLayer、Model、ForCausalLM |

后续若支持其他模型，通常也放在此目录下新增文件。

---

## `nanovllm/utils/` — 工具模块

| 文件 | 作用 |
|------|------|
| `loader.py` | 从 HuggingFace 风格权重目录加载参数到模型 |
| `context.py` | 推理全局上下文：是否 prefill、cu_seqlens、slot_mapping、block_tables 等，供 Attention 等层读取 |

---

## 推荐阅读顺序

1. `example.py` / `nanovllm/llm.py` — 弄清用户 API  
2. `engine/llm_engine.py` → `scheduler.py` → `sequence.py` — 理解请求如何被调度  
3. `engine/block_manager.py` — 理解 KV Cache 与 Prefix Caching  
4. `engine/model_runner.py` — 理解实际如何跑模型  
5. `models/qwen3.py` + `layers/*` — 理解模型与算子细节  
6. `utils/loader.py`、`utils/context.py` — 补齐权重加载与跨层上下文
